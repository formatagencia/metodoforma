# MÉTODO FORMA — Landing Page

Projeto estático pronto para publicação no GitHub Pages.

## Publicação

1. Envie todos os arquivos desta pasta para a raiz do repositório no GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main`, a pasta `/ (root)` e salve.

O site não exige instalação, compilação ou `node_modules`.

## Meta Pixel

O `PageView` é disparado no carregamento. O evento `Lead` é disparado quando a página é aberta com o parâmetro `?lead=success`. Configure o formulário externo para redirecionar à URL publicada com esse parâmetro após uma submissão bem-sucedida.
